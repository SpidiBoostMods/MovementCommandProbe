# MovementCommandProbe

Тестовый мод SpidiBoost для Fabric 1.21.4. Проверяет `/checkmute` игроков из текущего TAB и записывает замеры в CSV.

- `/cmprobe start` — обычная последовательная отправка. После команды начинай двигаться, как при обычной игре.
- `/cmprobe start idle` — отправка после остановки. Клавиши движения и горизонтальная скорость откладывают следующую команду.
- `/cmprobe delay 1000` — интервал между отправками в миллисекундах. По умолчанию 1000, допускается 250–60000.
- `/cmprobe settle 250` — сколько ждать после остановки. По умолчанию 250 мс.
- `/cmprobe stop` — остановить и сохранить отчёт.
- `/cmprobe open` — открыть последний отчёт.

При первом ChatC, отказе сервера или отсутствии ответа за четыре секунды тест останавливается. Нужны права на `/checkmute`. Во время теста дождись завершения других проверок, использующих `/checkmute`, чтобы ответы можно было связать с запросами.

Отчёты лежат в `logs/command-probe` текущего инстанса. В строках указаны ник, режим, интервалы, клавиши движения, спринт, приседание, горизонтальная скорость, время после остановки, ответ или ChatC и его задержка. Отсутствие ответа записывается как `timeout`.

Для сравнения повторяй проверку с разными `settle`, например 100, 250 и 500 мс. Сравнивай строки, где было движение или малая пауза после него. Мод отправляет обычные команды через сетевой обработчик Minecraft.
