# MovementCommandProbe

Тестовый мод SpidiBoost для Fabric 1.21.4. Автоматически подбирает вариант отправки `/checkmute` при движении и записывает замеры.

- `/cmprobe start` — полный автотест. Закрой чат и двигайся до завершения. Если движения нет 20 секунд, мод сохраняет промежуточный отчёт.
- `/cmprobe start manual` — обычная отправка всего TAB с ручным интервалом.
- `/cmprobe start idle` — отправка всего TAB после остановки.
- `/cmprobe delay 1000` — интервал ручных режимов. По умолчанию 1000 мс, допускается 250–60000.
- `/cmprobe settle 250` — ожидание после остановки для ручного режима `idle`.
- `/cmprobe stop` — остановить и сохранить отчёт.
- `/cmprobe open` — открыть сводный отчёт TXT.
- `/cmprobe csv` — открыть подробные замеры CSV.

Автотест перебирает восемь сочетаний. Обычная отправка проверяется с интервалами 1000 и 2000 мс. Варианты с временным сбросом ввода проверяются с интервалами 250–1000 мс и ожиданием 0–2 тика. Текущий ввод восстанавливается на следующем тике после команды. Возможны короткие рывки движения.

Каждый вариант должен получить три ответа при движении. После ChatC, другого собственного срабатывания AC или таймаута автотест делает паузу и переходит дальше. Затем самый быстрый успешный кандидат проходит повторную проверку по всем уникальным никам TAB. При ошибке проверяется следующий кандидат. Если ни один не прошёл, отчёт сообщает об этом. Отказ в правах и отключение останавливают тест. Другая проверка `/checkmute` также останавливает замер, чтобы не смешивать ответы.

Отчёты лежат в `logs/command-probe` текущего инстанса. В CSV указаны ник, этап, вариант, заданный и фактический интервалы, ожидание после сброса ввода, клавиши движения, спринт, приседание, скорость, ответ, ChatC и задержка ответа. TXT содержит результаты каждого варианта и прошедшего TAB кандидата. Успех относится к условиям этого запуска. Отчёты помогут выбрать и повторно проверить настройки для основных модов.
