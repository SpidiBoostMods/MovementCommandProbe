# MovementCommandProbe

Тестовый мод SpidiBoost для Fabric 1.21.4. Автоматически подбирает вариант отправки `/checkmute` при движении и записывает замеры.

- `/cmprobe start` — полный автотест. Сначала выполняется контроль стоя. После сообщения об успешном контроле двигайся до завершения. Если двигаться сразу, контроль будет пропущен через пять секунд. Если движения нет 20 секунд во время основной серии, мод сохраняет промежуточный отчёт.
- `/cmprobe start manual` — обычная отправка всего TAB с ручным интервалом.
- `/cmprobe start idle` — отправка всего TAB после остановки.
- `/cmprobe delay 1000` — интервал ручных режимов. По умолчанию 1000 мс, допускается 250–60000.
- `/cmprobe settle 250` — ожидание после остановки для ручного режима `idle`.
- `/cmprobe stop` — остановить и сохранить отчёт.
- `/cmprobe open` — открыть сводный отчёт TXT.
- `/cmprobe csv` — открыть подробные замеры CSV.

Автотест перебирает десять сочетаний. Проверяется обычная отправка, сброс одного ввода и сброс ввода вместе со спринтом. Интервалы — 250–2000 мс. Отправка сравнивается в двух местах сетевого тика — до штатных пакетов состояний и после них, перед пакетом движения. Временные состояния восстанавливаются сразу после команды, до отправки движения этого же тика. При приседании автотест ждёт его отпускания. Возможны короткие рывки движения.

Каждый вариант должен получить три ответа при движении. После ChatC, другого собственного срабатывания AC или таймаута автотест делает паузу и переходит дальше. Затем самый быстрый успешный кандидат проходит повторную проверку по всем уникальным никам TAB. При ошибке проверяется следующий кандидат. Если ни один не прошёл, отчёт сообщает об этом. Отказ в правах и отключение останавливают тест. Другая проверка `/checkmute` также останавливает замер, чтобы не смешивать ответы.

Отчёты лежат в `logs/command-probe` текущего инстанса. В CSV указаны ник, этап, вариант, заданный и фактический интервалы, место отправки внутри тика, снятие состояний спринта/приседания, клавиши движения, скорость, ответ, ChatC и задержка ответа. При таймауте сохраняются полученные строки ответа с именем цели или заголовком проверки. TXT содержит результат контроля стоя, результаты каждого варианта и прошедшего TAB кандидата. Ответ с последующим срабатыванием AC исключает кандидата. Успех относится к условиям этого запуска.
